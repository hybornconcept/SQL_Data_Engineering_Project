# SQL Data Engineering Projects

This repository is a collection of SQL exercises and analyses for practicing data engineering concepts. It includes lessons on working with SQL and an exploratory analysis of skills requested in data engineering job postings.

## Project: Exploratory Data Analysis

The EDA project uses SQL to compare skill demand and reported salaries for remote data engineer roles. The analysis covers frequently requested skills, higher-paying skills, and skills that balance demand with compensation.

![Data warehouse diagram](./Lessons/1_EDA/Images/1_2_Data_Warehouse.png)

Read the [EDA project guide](./Lessons/1_EDA/README.md) for the questions, approach, and findings. The queries are available individually:

- [Most demanded skills](./Lessons/1_EDA/01_top_demanded_skils.sql)
- [Highest-paying skills](./Lessons/1_EDA/02_top_paying_skills.sql)
